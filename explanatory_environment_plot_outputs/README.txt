Explanatory environment plots generated from the main environment module.

The script imports standard_trajectory_rl_environment.py and adds explanatory annotations only.
It does not redefine the environment mechanics and does not show final sensor deployment results.

Figures:
1. Physical trajectory generation with an annotated sample trajectory.
2. Mapping from physical trajectory to representation/state point l=(alpha,p).
3. Counterfactual one-sensor reward field over the physical arena.
4. Sensor sensing response gamma(l,s) in representation space.
